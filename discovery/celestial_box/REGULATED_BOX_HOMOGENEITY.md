# Exact homogeneity of the regulated scalar box

Codex/GPT discovery track, 2026-08-25.

Use the Euclidean variables of the exact dispersive closure,

S>0, U>0, m=mu^2>0,

with

R^2 = U/(U+4m),

kappa^2 = [S(U+4m)-4m^2]/(S U),

and

J(-S,-U;m)
 = 2/(kappa S U)
   [F_alpha(y)-F_(alpha^-1)(y)-F_alpha(1)+F_(alpha^-1)(1)],

where y=(1+R)/(1-R) and alpha=(1-kappa)/(1+kappa).

Under a common positive scale c,

(S,U,m) -> (cS,cU,cm),

both dimensionless shape variables are exactly invariant:

R(cU,cm)^2 = R(U,m)^2,

kappa(cS,cU,cm)^2 = kappa(S,U,m)^2.

Therefore y and alpha are unchanged, while

1/[(cS)(cU)] = c^(-2)/(S U).

Hence the complete regulated box obeys the exact homogeneity law

boxed:

J(-cS,-cU;cm) = c^(-2) J(-S,-U;m),  c>0.

This is the expected mass-dimension -4 of a four-dimensional scalar box when S,U,m each carry mass-dimension two, but here it follows directly from the exact dispersive/dilogarithmic closure with the regulator retained.

The endpoint identity

1-kappa^2 R^2 = 4m^2/[S(U+4m)]

is likewise invariant under the same common scaling, confirming that the regulator-controlled IR shape depends only on dimensionless ratios.

Consequences for celestial shifts:

1. External-energy Mellin shifts alter the homogeneous prefactor through Mandelstam monomials, while the scalar-box shape can be organized in scale-free ratios.
2. The regulator must be tracked with its own mass dimension; holding m fixed while scaling external energies is not the same symmetry.
3. This identity concerns the scalar box only and does not establish the full Yang-Mills or gravity numerator/state sum.
