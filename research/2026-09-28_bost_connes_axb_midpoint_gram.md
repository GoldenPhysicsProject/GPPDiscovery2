## 1. Critical KMS restriction to the additive phase algebra

The Bost-Connes algebra is generated by multiplicative isometries \(\mu_n\) and phase unitaries
\[
e(r),\qquad r\in\mathbb Q/\mathbb Z,
\]
with
\[
e(r)\mu_n=\mu_ne(nr),
\]
and
\[
\mu_ne(r)\mu_n^*
=
\frac1n\sum_{ns=r}e(s).
\]

For \(0<\beta\le1\), the unique KMS state has
\[
\omega_\beta(e(a/b))
=
b^{-\beta}
\prod_{p\mid b}\frac{1-p^{\beta-1}}{1-p^{-1}}
\]
for \(a/b\) reduced.

At the critical point \(\beta=1\),
\[
\boxed{
\omega_1(e(r))=
\begin{cases}
1,&r=0,\\
0,&r\ne0.
\end{cases}
}
\]
So the additive algebra is exactly in its Haar state.

## 2. Ordered basis \(\mu_ne(r)\)

Set
\[
A_{n,r}:=\mu_ne(r).
\]

The midpoint form is
\[
\langle X,Y\rangle_{\rm mid}
=
\omega_1(X^*\sigma_{i/2}(Y)).
\]

Because
\[
\sigma_t(A_{n,r})=n^{it}A_{n,r},
\]
time-invariance kills different \(n\)-frequencies. For \(m=n\),
\[
A_{n,r}^*A_{n,s}=e(s-r).
\]

Hence
\[
\boxed{
\langle A_{m,r},A_{n,s}\rangle_{\rm mid}
=
\delta_{mn}\delta_{rs}\,n^{-1/2}.
}
\]

Thus the critical midpoint completion contains an orthogonal tensor-like basis of multiplicative energy \(n\) and additive phase \(r\), with the exact half-density metric.

## 3. Opposite ordering \(e(r)\mu_n\) detects the semidirect product

Now set
\[
B_{n,r}:=e(r)\mu_n.
\]

For \(m=n\),
\[
B_{n,r}^*B_{n,s}
=
\mu_n^*e(s-r)\mu_n
=
e(n(s-r)).
\]

Therefore
\[
\boxed{
\langle B_{m,r},B_{n,s}\rangle_{\rm mid}
=
\delta_{mn}n^{-1/2}
\mathbf 1_{\{n(s-r)=0\text{ in }\mathbb Q/\mathbb Z\}}.
}
\]

So changing operator ordering converts the orthogonal phase basis into the finite \(n\)-torsion incidence geometry.

This is an exact ax+b coupling between multiplicative scale and additive lattice data. It is the algebraic structure that the prime torus alone lacks.

## 4. Range projections are finite additive averages

Putting \(r=0\) in the Bost-Connes transfer relation gives

This is a precise arithmetic coarse-graining identity, not an analogy.

## 5. The midpoint two-point function gives the prime Fourier current

For a finite cutoff define
\[
J_N=\sum_{n\le N}\sqrt{\Lambda(n)}\,\mu_n.
\]

Then
\[
\boxed{
\omega_1\!\left(
J_N^*\sigma_{u+i/2}(J_N)

\sum_{n\le N}
\frac{\Lambda(n)}{\sqrt n}
e^{iu\log n}.

So the critical finite-place explicit-formula current is literally a Bost-Connes KMS two-point function.

## 6. Important variable mismatch: why this still does not prove Weil positivity

Let \(f\) be a logarithmic-line test function and
\[
h=f*\widetilde f.
\]

The Weil prime term samples
\[
h(\log n)
=
\langle f,T_{\log n}f\rangle,
\]
where \(T_a\) is translation on the test-function line.

If instead one smears the KMS current in modular time,
\[
J_g=\int g(u)\sigma_u(J)\,du,
\]
then midpoint positivity gives
\[
\|J_g\|_{\rm mid}^2
=
\sum_n\frac{\Lambda(n)}{\sqrt n}
|\widehat g(\log n)|^2.
\]

These are NOT the same expression:
\[
h(\log n)
\ne
|\widehat f(\log n)|^2
\]
in general.

This is the exact reason that "local KMS positivity implies Weil positivity" is too quick.

Weil needs the prime channel as a CROSS-TRANSLATION term, not a diagonal spectral sample.

## 7. TFD/jump completion of the cross term

The cross-translation term has an exact positive parent:
\[
\|f-T_Lf\|_2^2
=
2h(0)-2\Re h(L).
\]

Therefore for every finite cutoff,
\[
\boxed{
\sum_{n\le N}\frac{\Lambda(n)}{\sqrt n}
\|f-T_{\log n}f\|_2^2
=
2\sum_{n\le N}\frac{\Lambda(n)}{\sqrt n}
[h(0)-\Re h(\log n)].
}
\]

This is a genuine positive Dirichlet/jump norm built from the same critical KMS channel weights.

The price is the divergent diagonal

Hence the Archimedean/pole completion must renormalize the DIAGONAL part while leaving the negative cross term intact. This is precisely the ground-state-transform/Poincare structure already found independently.
